FFmpeg のソースコード

BulkDL には、動画の詰め替え（remux）のために FFmpeg 9.0.2 が含まれています。FFmpeg は GNU 劣等一般公衆利用許諾書（LGPL）2.1 版以降の下で配布されています。

アプリに含まれる FFmpeg は、次のソースコードとビルドスクリプトから作っています。ソースコードは改変していません。利用者は、FFmpeg を改変したものに差し替えることができます。

  • ffmpeg-9.0.2.tar.xz（FFmpeg 9.0.2 のソースコード）
  • build-android.sh（Android 用のビルドスクリプト。LGPL の構成でビルドします）

FFmpeg source code

BulkDL includes FFmpeg 9.0.2 for remuxing, licensed under the GNU Lesser General Public License version 2.1 or later. The unmodified source code and the build script used for the app are available above. You may replace FFmpeg with a modified version.
